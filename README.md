  ## 📊 OLIST Store Sales Dashboard (Power BI)

   # 📌 Project Overview

This project is an interactive **Power BI Dashboard** built using the **Brazilian OLIST E-Commerce Dataset**. The dashboard provides business insights into sales, profit, customers, payments, shipping performance, and order trends to help stakeholders make data-driven decisions.

---

   ## 🎯 Objectives

- Analyze overall sales performance.
- Track profit and profit margin.
- Monitor customer purchasing behaviour.
- Compare weekday vs weekend sales.
- Analyze payment methods.
- Evaluate shipping performance and customer review scores.

---

   ## 📌 Business Insights

- Credit Card is the most preferred payment method.
- Weekend transactions contribute significantly to overall sales.
- Faster deliveries generally receive better customer review scores.
- São Paulo has a high average payment value compared to average product price.
- Dashboard enables quick filtering for customer and payment analysis.
